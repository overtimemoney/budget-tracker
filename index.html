Automate it (iPhone Shortcuts)

Apple does not let any app — web or native — read another app’s notifications on iPhone, so no tracker can silently watch BofA/Capital One for you. The closest real automation on iOS uses text-message alerts + a Shortcut:

One-time setup (~3 min):

  • In the BofA and Capital One apps, turn on text alerts for purchases (any amount).
  • Open Apple’s Shortcuts app → Automation → + → Message → set “Message Contains” to $ → choose Run Immediately.
  • Add these actions in order: URL Encode (the incoming message) → Text: https://overtimemoney.github.io/budget-tracker/#import= followed by the Encoded Text → Open URLs.
  • Done: each bank text opens this tracker and files the transaction itself (duplicates are skipped). Prefer less interruption? Swap “Open URLs” for Append to Note into a note called “Budget Inbox”, then paste that note here in one go whenever you like.
  • Apple Pay purchases: same recipe, but start the automation from the Transaction trigger instead of Message.

Venmo doesn’t offer purchase texts — for Venmo, the email-alert route (ask Luna) or a quick paste here covers it.

Security

How this app stays safe:

  • No bank login, ever. It is not connected to BofA, Capital One, Venmo, or any bank account.
  • No cloud backup, no analytics, no relay. By default the app sends your data nowhere. If you turn on Gmail sync below, the app talks only to Google to read alert emails you authorized — the Google access token stays in memory (never stored), and imported transactions live only on this device.
  • Everything is stored only in this browser on this device. The code on GitHub contains none of your financial data.
  • Uninstalling / clearing site data erases everything — export a backup first if you want to keep it.

Optional. Connect your own Google account and the app reads only transaction-alert emails from Venmo, Capital One and BofA, parses them right here on your phone, and files them as transactions. Nothing goes to Luna, GitHub, or any relay — the app talks to Google directly, and only while you use it.

One-time Google setup (about 5 minutes)
  1. Open console.cloud.google.com and create a project (any name, e.g. “My Budget”).
  2. Search for Gmail API and click Enable.
  3. Go to Google Auth platform → Branding: app name “My Budget”, support email = your Gmail. Under Audience choose External (this is a personal-use app — Google will show an “unverified app” warning when you connect; that’s expected, choose Advanced → continue).
  4. Go to Google Auth platform → Clients → Create Client → Web application.
  5. Under Authorized JavaScript origins add exactly: https://overtimemoney.github.io
  6. Create it, copy the Client ID (it ends in .apps.googleusercontent.com) and paste it above. No client secret and no API key are needed — never share a secret.
