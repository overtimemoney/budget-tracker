🤖 Automate it (iPhone Shortcuts)

Apple does not let any app — web or native — read another app’s notifications on iPhone, so no tracker can silently watch BofA/Capital One for you. The closest real automation on iOS uses text-message alerts + a Shortcut:

One-time setup (~3 min):

  • In the BofA and Capital One apps, turn on text alerts for purchases (any amount).
  • Open Apple’s Shortcuts app → Automation → + → Message → set “Message Contains” to $ → choose Run Immediately.
  • Add these actions in order: URL Encode (the incoming message) → Text: https://overtimemoney.github.io/budget-tracker/#import= followed by the Encoded Text → Open URLs.
  • Done: each bank text opens this tracker and files the transaction itself (duplicates are skipped). Prefer less interruption? Swap “Open URLs” for Append to Note into a note called “Budget Inbox”, then paste that note here in one go whenever you like.
  • Apple Pay purchases: same recipe, but start the automation from the Transaction trigger instead of Message.

Venmo doesn’t offer purchase texts — for Venmo, the email-alert route (ask Luna) or a quick paste here covers it.

🔒 Security

How this app stays safe:

  • No bank login, ever. It is not connected to BofA, Capital One, Venmo, or any account.
  • No accounts, no cloud, no analytics. The app makes zero network requests with your data.
  • Everything is stored only in this browser on this device. The code on GitHub contains none of your financial data.
  • Uninstalling / clearing site data erases everything — export a backup first if you want to keep it.
